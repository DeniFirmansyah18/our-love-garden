# Foto kalian

Taruh foto di folder ini dengan nama berikut:

- `foto-1.jpg` — dipakai di peti kenangan "Pertama kali"
- `foto-2.jpg` — dipakai di peti kenangan "Rumah miring"
- `foto-3.jpg` — dipakai di peti kenangan "Selalu pulang"
- `foto-4.jpg` — cadangan, bebas dipakai untuk bingkai foto rumah

Rasio paling enak dilihat di bingkai: **4:3 atau persegi**, minimal 600 px,
ukuran file di bawah 300 KB per foto supaya tetap ringan di HP.

Kalau file belum ada, game tetap jalan: bingkai memakai ilustrasi polaroid
prosedural sebagai gantinya, jadi tidak ada gambar rusak.

Mau mengganti pasangan foto dan peti? Ubah `photo` pada entri di
`src/data/memories.ts`, lalu taruh file dengan nama yang sama di folder ini.

Catatan: semua gambar di folder ini khusus untuk hadiah pribadi. Jangan
meng-upload foto kalian ke layanan publik tanpa izin satu sama lain.
